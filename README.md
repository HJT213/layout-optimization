# layout-optimization
使用 Python 和 NumPy 实现遗传算法，在避免家具碰撞、保持门前区域和通道畅通的约束下，联合优化家具位置、朝向与窗位。覆盖卧室、卫生间、厨房和客厅的标准与紧凑版共 8 个场景。基于 Three.js 交互展示已有实验结果，可切换房型、算法和随机种子，对比优化前后的三维布局与收敛曲线。

## 项目简介

给定房间尺寸、门的位置和家具清单，程序联合优化家具的摆放位置、朝向以及单扇窗户的位置。项目覆盖卧室、卫生间、厨房和客厅，每种房型均有标准版和紧凑版，共 8 个仿真场景。

## 在线演示

打开演示页面，可以选择「厨房 → 紧凑 → 遗传算法 → 种子 20」。左侧是初始布局，右侧是优化结果。拖动任一模型可同步旋转两侧视角，也可以切换俯视图，查看家具是否占用通道。保持房型和种子不变，切换算法即可对比结果；「实验分析」提供收敛曲线和可行解次数。

## 技术方案

- **布局建模：** 用连续参数表示家具位置和窗户沿墙的位置，用离散参数表示家具朝向和窗户所在墙面。将家具不重叠、不侵占门前区和预留通道设为硬约束，再按家具间距、功能关系与窗位偏好评分。
- **优化算法：** 使用 Python 和 NumPy 实现带精英保留的遗传算法，并与随机搜索、无变异遗传算法对照。
- **三维展示：** 使用 Three.js 将二维求解结果呈现为可旋转、缩放的三维场景。网页回放预先生成的实验结果，不在浏览器中重新运行 Python。

## 实验结果

主实验共 720 次运行。同一房型、同一种子下，三种算法使用相同的初始种群和候选评估预算。

| 方法 | 获得可行解的次数 | 可行率 |
| --- | ---: | ---: |
| 遗传算法 | 240 / 240 | 100% |
| 随机搜索 | 162 / 240 | 67.50% |
| 无变异遗传算法 | 191 / 240 | 79.58% |

可行率表示找到满足模型硬约束的布局的比例。结果仅适用于本项目的仿真场景，不代表对真实住宅的设计验证。
